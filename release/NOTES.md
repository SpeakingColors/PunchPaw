PunchPaw 0.1.0 (test build). A free, open source punch compressor for drums and bass (VST3).

One zip: installers for Windows (.exe) and Linux (Flatpak extension plus a plain .vst3), the PDF manual with an interface tour, INSTALL.txt and SHA256SUMS. Everything works offline; the plugin collects nothing.

The macOS .pkg is not in this zip: GitHub's macOS build machines were unavailable (capacity). It will be added by a re-run as soon as one is free; see the open macOS issue.

The installers are not code-signed or notarised. Windows may say "unknown publisher" (More info, Run anyway); macOS may need Privacy and Security, Open Anyway. This is not a sign of harm: the code is open and the zip has SHA256SUMS to check it.

This is a test build: automated tests and pluginval pass in CI, but it has not been checked by ear in real hosts or installed on real Windows and macOS machines yet. See ROADMAP.md.
